# Proton Mail Web Automation QA Assessment

## Overview

This project contains a Java-based Selenium WebDriver automation framework created for the Proton Mail Web Automation QA assessment.

The project demonstrates:

- Risk-based test design
- Page Object Model
- Selenium WebDriver
- TestNG
- Maven
- Reusable browser setup
- Explicit synchronization
- Environment-based test credentials
- Negative test coverage
- Failure/debugging considerations

## Technology Stack

- Java 17
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Eclipse IDE
- Chrome
